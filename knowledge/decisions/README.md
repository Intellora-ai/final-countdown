# decisions

Past decisions and WHY they were made.

The why is the whole point. Code shows what was chosen; only this folder can
show what was rejected and on what evidence. Without it, the next person
re-litigates a settled question, or worse, silently reverses it.

One file per decision: `NNNN-short-title.md`. Include the date, the options
considered, the evidence, the decision, and the consequences accepted.
A decision that is later reversed is not deleted -- it is marked superseded,
with a link to the one that replaced it.
