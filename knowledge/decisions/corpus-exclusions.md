# Corpus exclusions and licence constraints

**Date:** 2026-08-29.
**Scope:** which of the twenty requested knowledge sources were mirrored under
`knowledge/`, which were not, and the licence terms that bind the ones that were.

Every source below was checked against the GitHub API — existence, size,
licence, archived status, default branch — and the LICENSE body was read by hand
wherever the SPDX detector returned `NOASSERTION`. None of this is assumed.

---

## Not mirrored

### developer-roadmap — moved, and the licence restricts redistribution

`kamranahmedse/developer-roadmap` no longer exists at that path. The API
redirects to `nilbuild/developer-roadmap` (354 MB). Its licence is custom, not a
standard open one, and it restricts sharing the content "from any other medium
including but not limited to blog".

**Decision: not mirrored.** This repository is public and company-owned, so
unclear redistribution terms are a real risk, not a technicality. The router
references it **by URL only**.

### devdocs — a browser, not a corpus

`freeCodeCamp/devdocs` is MPL-2.0 and 32 MB, so the licence is not the problem.
DevDocs is a **documentation browser**: the documentation itself is scraped at
runtime and is **not in the repository**. Mirroring it would install scrapers and
zero content.

**Decision: not mirrored.** API-reference lookups route to `mdn/content` plus the
current official documentation for whatever is being looked up.

### cs50 — no licence at all

`cs50/lectures` is 395 MB with **no licence file**. No licence means all rights
reserved, not public domain. The rest of the `cs50` organisation is tooling —
`libcs50`, `check50`, `submit50` — which is software, not knowledge.

**Decision: cannot be mirrored.** CS-foundations questions route to `ossu` and
`freeCodeCamp`, both already installed and both properly licensed.

### nand2tetris — an organisation, and the book is not on GitHub

`nand2tetris` is a GitHub organisation, not a repository. Only
`nand2tetris/projects` (<1 MB) was added; `web-ide` (46 MB) is application code,
not teaching material.

**Recorded so the router does not oversell it:** `nand2tetris/projects` is
**exercise skeletons, not explanation**. The textbook that explains the exercises
is not on GitHub and is not in this corpus. Routing a "how does a CPU work"
question here alone will return stubs and no answer.

## Mirrored, with a NonCommercial licence constraint

These **are** in the corpus. The constraint is written here so that it is a
recorded fact rather than something a future session has to remember.

| Source | Path | Licence |
|---|---|---|
| `progit/progit2` | `knowledge/progit` | **CC BY-NC-SA 3.0** |
| 55 OpenStax `osbooks-*` repositories | `knowledge/openstax/*` | **CC BY-NC-SA** (see below) |

**NC means NonCommercial.** The material may be read, studied and adapted for
non-commercial use with attribution and share-alike. It may **not** be
redistributed or reused as part of a commercial product. Treat it as background
reading for engineers, never as content to ship.

Both were mirrored on the owner's explicit decision, made after being shown the
NonCommercial term.

### The OpenStax licence detail

The GitHub licence detector disagrees with the repositories themselves:

- **13 of 55** report `CC-BY-4.0` to the API.
- **42 of 55** report `NOASSERTION` — the detector found no standard licence file.

Reading the `NOASSERTION` repositories' own READMEs shows they state **CC BY-NC-SA**.
So the API answer is not usable, and the safe reading — the one recorded here —
is that the whole OpenStax set carries the **NonCommercial** term. Do not assume
plain CC-BY across all 55 because 13 of them report it.

Each repository's per-repo licence string is carried in `knowledge/README.md`,
which is generated by `scripts/knowledge_manifest.py` and must never be
hand-edited.
